# DocumentationPractice

## Deskripsi Proyek
DocumentationPractice adalah proyek Java sederhana yang dibuat untuk memenuhi CODELAB 2 praktikum Pemrograman Lanjut.

## Tujuan
- Memahami dokumentasi perangkat lunak.
- Menjelaskan informasi dasar proyek Java.
- Memberikan panduan penggunaan program.

## Teknologi
- Bahasa pemrograman: Java
- IDE: IntelliJ IDEA
- JDK: Java Development Kit
- Dokumentasi: Markdown

## Struktur Proyek
- `src/Main.java`: berisi kode utama program.
- `README.md`: berisi dokumentasi proyek.

## Cara Menjalankan Program
1. Buka proyek DocumentationPractice di IntelliJ IDEA.
2. Pastikan JDK sudah dikonfigurasi.
3. Buka `src/Main.java`.
4. Klik kanan, lalu pilih Run `Main.main()`.
5. Lihat hasil program pada jendela Run.

## Penjelasan Program
Kelas Main merupakan kelas utama program. Metode `main()` menjadi titik awal eksekusi aplikasi, sedangkan `System.out.println()` digunakan untuk menampilkan teks ke konsol.

## Kesimpulan
README.md berfungsi untuk menjelaskan proyek dan memberikan petunjuk menjalankan program sehingga lebih mudah dipahami oleh pengguna maupun pengembang lain.
